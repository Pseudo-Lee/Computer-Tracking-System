# CMPG223-ComputerTrackingSystemt

## Purpose
This repository contains a past CMPG223 group project focused on a **computer tracking system**.

The main goal of the project is to help track computer-related records in one place, making it easier to manage and monitor assets over time.

## Project Context
This project was originally created about two years ago by classmates working together.  
The original repository was deleted, and this repository serves as a restored copy with basic documentation.
